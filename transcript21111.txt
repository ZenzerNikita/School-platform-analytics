## Основная часть

### 1. Неопределённый интеграл и первообразная

**Преподаватель:** Пусть дана функция ( f(x) ). Функция ( F(x) ) называется первообразной для ( f(x) ), если
[
F'(x)=f(x).
]

**Преподаватель:** Например, для функции ( f(x)=2x ) одной из первообразных будет ( F(x)=x^2 ), потому что производная ( x^2 ) равна ( 2x ).

**Преподаватель:** Но здесь есть важная деталь. Производная функции ( x^2+5 ) тоже равна ( 2x ). Производная функции ( x^2-17 ) тоже равна ( 2x ). Поэтому первообразная не одна. Их бесконечно много.

**Преподаватель:** Поэтому мы записываем:
[
\int f(x),dx = F(x)+C,
]
где ( C ) — произвольная постоянная.

**Преподаватель:** Проверим понимание. Почему в ответе появляется ( C )?

**Студент 3:** Потому что производная любой константы равна нулю.

**Преподаватель:** Совершенно верно. Если при дифференцировании постоянная исчезает, то при обратной операции мы должны учитывать все возможные постоянные.

**Преподаватель:** Короткий вопрос для всех. Если
[
\int 3x^2,dx = x^3+C,
]
как проверить, что ответ верный?

**Студентка 4:** Нужно взять производную от ( x^3+C ) и получить ( 3x^2 ).

**Преподаватель:** Да. Это главный способ самопроверки для неопределённых интегралов: продифференцировать ответ.

### 2. Аналогия: интеграл как восстановление целого по изменениям

**Преподаватель:** Представьте, что у вас есть бак с водой. Вы не видите, сколько воды в баке в каждый момент времени, но знаете скорость поступления воды: сколько литров в минуту добавляется. Если вы хотите узнать, сколько воды поступило за промежуток времени, вам нужна операция накопления. Производная описывает мгновенное изменение, а интеграл описывает накопленный результат.

**Преподаватель:** В физике это встречается постоянно. Если известна скорость движения тела, интеграл скорости по времени даёт перемещение. Если известна мощность устройства, интеграл мощности по времени даёт энергию. Если известна плотность распределения массы, интеграл позволяет найти массу.

**Преподаватель:** Поэтому интеграл не следует воспринимать только как формальный символ. Это инструмент для перехода от локального изменения к накопленному результату.

**Преподаватель:** Сформулируйте своими словами: что накапливает интеграл, если функция ( v(t) ) описывает скорость?

**Студент 5:** Он накапливает пройденное расстояние или перемещение.

**Преподаватель:** Точнее: интеграл скорости даёт перемещение. Если скорость неотрицательна, это совпадает с пройденным путём. Отличное замечание.

### 3. Определённый интеграл

**Преподаватель:** Теперь перейдём к определённому интегралу. Он записывается так:
[
\int_a^b f(x),dx.
]

**Преподаватель:** В отличие от неопределённого интеграла, здесь результатом является число. Это число связано с накоплением значений функции на отрезке от ( a ) до ( b ).

**Преподаватель:** Если функция ( f(x) ) неотрицательна на отрезке ([a;b]), то определённый интеграл можно интерпретировать как площадь под графиком функции на этом отрезке.

**Преподаватель:** Рассмотрим простой пример:
[
\int_0^3 2,dx.
]

**Преподаватель:** Функция равна двум на всём отрезке от 0 до 3. Графически это прямоугольник высотой 2 и шириной 3. Его площадь равна ( 2\cdot 3=6 ). Поэтому:
[
\int_0^3 2,dx=6.
]

**Преподаватель:** Это пример показывает один важный смысл определённого интеграла: он измеряет накопленную величину на промежутке.

**Преподаватель:** Теперь вопрос. Если взять
[
\int_0^3 5,dx,
]
какой будет ответ?

**Студентка 6:** ( 15 ), потому что высота 5, ширина 3.

**Преподаватель:** Верно. Проверка пройдена.

---

### 4. Интегральные суммы

**Преподаватель:** Теперь объясним, откуда берётся определённый интеграл в строгом смысле. Представьте, что график функции сложный, и площадь под ним нельзя сразу выразить как площадь прямоугольника или треугольника. Тогда мы делим отрезок на маленькие части и на каждой части заменяем криволинейную фигуру прямоугольником.

**Преподаватель:** Если отрезок ([a;b]) разбит на ( n ) малых отрезков, то на каждом малом отрезке мы берём значение функции ( f(\xi_i) ) и умножаем его на длину этого отрезка ( \Delta x_i ). Получается сумма:
[
\sum_{i=1}^{n} f(\xi_i)\Delta x_i.
]

**Преподаватель:** Такая сумма называется интегральной суммой.

**Преподаватель:** Когда мы делаем разбиение всё более мелким, прямоугольники всё точнее приближают площадь под графиком. В пределе получаем определённый интеграл:
[
\int_a^b f(x),dx
================

\lim_{\max \Delta x_i \to 0}
\sum_{i=1}^{n} f(\xi_i)\Delta x_i.
]

**Преподаватель:** Обратите внимание на идею: интеграл возникает как предел сумм. Мы сначала складываем много маленьких вкладов, а затем рассматриваем предельный случай, когда эти вклады становятся бесконечно малыми.

**Преподаватель:** Проверка понимания. Что означает множитель ( \Delta x_i ) в интегральной сумме?

**Студент 7:** Длину маленького промежутка.

**Преподаватель:** Верно. А что означает ( f(\xi_i) )?

**Студентка 8:** Значение функции в выбранной точке этого промежутка.

**Преподаватель:** Да. Тогда произведение ( f(\xi_i)\Delta x_i ) — это вклад маленького прямоугольника.

---

### 5. Формула Ньютона — Лейбница

**Преподаватель:** Строгое определение через предел интегральных сумм важно для понимания, но вычислять интегралы чаще всего удобнее другим способом. Для этого используется формула Ньютона — Лейбница:
[
\int_a^b f(x),dx = F(b)-F(a),
]
где ( F(x) ) — первообразная функции ( f(x) ).

**Преподаватель:** Рассмотрим пример:
[
\int_1^3 2x,dx.
]

**Преподаватель:** Сначала находим первообразную для ( 2x ). Это ( x^2 ). Затем подставляем верхний и нижний пределы:
[
\int_1^3 2x,dx = x^2\bigg|_1^3 = 3^2-1^2=9-1=8.
]

**Преподаватель:** Значит,
[
\int_1^3 2x,dx=8.
]

**Преподаватель:** Теперь проверьте себя. Что было бы неверным действием в этом примере?

**Студент 9:** Забыть подставить нижний предел.

**Преподаватель:** Да. Частая ошибка — найти первообразную, подставить только верхний предел и остановиться. В определённом интеграле нужно вычислить разность ( F(b)-F(a) ).

**Преподаватель:** Ещё одна частая ошибка — перепутать порядок и записать ( F(a)-F(b) ). Тогда знак ответа будет неправильным.
